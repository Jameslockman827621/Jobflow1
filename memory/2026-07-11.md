# 2026-07-11 - JobScale End-to-End Audit

## Summary
Performed a full end-to-end audit of the JobScale SaaS at the user's request. Found several critical bugs and fixed them, then documented the remaining issues that prevent it from being "world-class" today.

## Fixes Applied
- **Extension**: fixed syntax errors in `extension/form_fill.js` (`o.value.toLowerCase().includes`) and `extension/popup.js` (incomplete ternary).
- **Frontend**: fixed JSX unescaped-entity lint errors in `apply/page.tsx`, `apply-settings/page.tsx`, `dashboard/page.tsx`, `priorities/page.tsx`.
- **Backend**: fixed undefined `DASHBOARD_URL` in `backend/app/api/auto_apply.py` that would crash `/auto-apply/auto-session/start`.
- **Backend**: made `cv_tailor.tailor_cv_for_job()` accept both ORM objects and dicts, matching its documented API.
- **Docs**: updated `QUICKSTART.md` to use `virtualenv` fallback and correct Celery module path.
- **Environment**: recreated `backend/venv` using `virtualenv` because `python3-venv` is missing from the cloud image.

## Audit Findings (Still Broken / Risky)
- **Database**: PostgreSQL 16 + Redis 7 required; not available in this environment, so DB-dependent endpoints cannot be tested end-to-end.
- **Scrapers**: Greenhouse and Ashby work; Lever returns 0 jobs for all listed companies; Workday returns 422.
- **Company directory**: only 138 companies, not 5,000+.
- **Job aggregator**: without Apify keys, real coverage is thin; demo seeded jobs dominate results.
- **Resume parser**: extracts skills but fails on name and experience.
- **Autonomous applier**: infrastructure exists but real-world reliability on multi-step ATS forms is unproven and risky.
- **Frontend build**: passes only because lint/type errors are ignored in `next.config.js`; `output: 'export'` + `rewrites()` is unsupported for static export.
