## Connect LinkedIn/Indeed → Easy Apply E2E

Shipped product path (not OAuth — LinkedIn has no Easy Apply OAuth scope):

1. Dashboard **Board connections** → Connect LinkedIn/Indeed
2. Extension reads cookies (`li_at` / Indeed auth) → `POST .../board-sessions/{board}/from-cookies`
3. Backend stores Playwright `storage_state` on `BoardSession`
4. Headless Easy Apply loads session; live board hosts without session return `needs_user` + `connect_hint`
5. Login wall after Connect invalidates session → reconnect prompt

Tests: `tests/test_connect_boards_e2e.py` + `tests/test_board_coverage.py` — 16 passed.
